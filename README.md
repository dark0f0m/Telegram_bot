# Telegram Bot — Погода и Дни рождения

Телеграм-бот, который показывает текущую погоду в Москве и напоминает о ближайших днях рождения (в течение 3 дней).

---

## Возможности

- 🌤 **Погода** — показывает текущую погоду в Москве (температура и описание)
- 🎂 **Дни рождения** — показывает дни рождения, которые наступят в ближайшие 3 дня

---

## Требования

- Python 3.8+
- Аккаунт Telegram и токен бота от [@BotFather](https://t.me/BotFather)
- API-ключ [OpenWeatherMap](https://openweathermap.org/api)
- Сервер с публичным HTTPS-адресом для webhook (например, [Railway](https://railway.app/))

---

## Установка

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/dark0f0m/Telegram_bot.git
   cd Telegram_bot
   ```

2. **Установите зависимости:**

   ```bash
   pip install -r requirements.txt
   ```

3. **Настройте параметры в `bot.py`:**

   | Параметр | Описание |
   |----------|----------|
   | `TELEGRAM_BOT_TOKEN` | Токен бота, полученный от @BotFather |
   | `API_KEY` (в `get_weather`) | Ваш API-ключ OpenWeatherMap |
   | URL в `bot.set_webhook(...)` | Публичный HTTPS-адрес вашего сервера |

4. **Добавьте дни рождения** в словарь `BIRTHDAYS` в `bot.py`:

   ```python
   BIRTHDAYS = {
       "Имя": {
           "date": "ГГГГ-ММ-ДД",
           "profile_link": "https://t.me/username",
           "info": "Краткое описание"
       },
       # ...
   }
   ```

---

## Запуск

```bash
python bot.py
```

Бот запустится на порту `5000` и установит webhook на указанный URL.

---

## Использование

1. Откройте бота в Telegram и отправьте команду `/start`.
2. Нажмите одну из кнопок:
   - **Погода** — получить текущий прогноз погоды в Москве.
   - **Дни рождения** — увидеть ближайшие дни рождения (в течение 3 дней).
